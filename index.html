Table to JSON Array Converter

1. Paste Table Data

2. Define Parsing Logic

Use a regular expression to capture columns. Example for CSV: `/(.*?),(.*?),(.*)/`

3. Map Columns to Fields

One per line, format: `capture_group_index:fieldName`. Example: `1:name`

4. Provide JSON Template

Use mapped field names as placeholders, e.g., `{id}`.
